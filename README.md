# Corral Hill Solar (iPhone web app)

Static home-screen web app. No data or topic names are stored in this repo.
On first open it shows Settings: enter the three ntfy topic names (data, alert, command) from the Pi's pi.env.
They are kept only in the phone's local storage.

Hosting: GitHub Pages from the repo root. Open the Pages URL in Safari, then Share > Add to Home Screen.
Add ?mock=1 to the URL to see sample data.
